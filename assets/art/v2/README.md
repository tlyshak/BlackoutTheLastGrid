# assets/art/v2 — згенеровані асети другої версії прологу (від автора, 2026-09-12)

Оригінали з `blackout_assets.zip`, **не редагувати**. Плоский вектор (SVG), Godot імпортує їх як текстури
з масштабом на імпорті.

- `keyframes/` — аркуші ключових кадрів 680×800: `rey_unarmed`, `rey_crowbar`, `dan`, `guard`.
  Ряди: стійка + 3 ключі ходьби + 2 стрибка; атака (замах/удар/вихід [+ удар ногою]); попадання/відкидання/нокдаун;
  idle-дихання 4 ключі. Це ключі, не повна анімація.
- `level0/` — три секції рівня 0 (забій / вентиляційна / вихід), ~680×440. Це **мокапи** з персонажами,
  конусом ліхтаря і лазерним променем усередині. Автор дозволив робити з них похідні копії без персонажів
  (див. `backgrounds/`, коли з'явиться); оригінали лишаються референсом.
