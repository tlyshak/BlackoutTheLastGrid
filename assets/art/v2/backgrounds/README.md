# assets/art/v2/backgrounds — фони рівня 0 без персонажів

Похідні копії мокапів `../level0/level0_section{1_mineface,2_ventilation,3_exit}.svg` (оригінали не
змінювались, лишаються референсом). Персонажі, конус ліхтаря, лазер-розтяжка і тіні під персонажами
вирізані; усе середовище (стіни, балки, кабелі, конвеєр, повербанки, вагонетка, ворота, панелі, лампи,
підлога, гори) лишено як є.

Усі файли: `viewBox="0 0 680 440"`, `width=680 height=440`, координати нижче — у цих одиницях (px viewBox).
Godot імпортує їх як текстури (scale на імпорті).

Вирізка робилась структурно (по індексах верхньорівневих елементів `<svg>`, без id): в оригіналах
персонажі — це окремі `<g>` (Рей: `stroke="#0b0909"`, шкіра `#d8a878`, куртка `#5a3a2a`; охоронець:
форма `#232a3e`/`#1b2030`, пов'язка `#c9403a`), конус — три `<path fill="#f2c451" opacity=…>` +
`<g clip-path="url(#cone)">` з пилинками, тінь — `<ellipse fill="#0b0909">`.

Розшарувати вдалося для всіх трьох секцій: в оригіналах елементи намальовані строго в порядку
«небо → гори → балка → стіна → підлога → пропи → персонажі → ефекти», без перекриття між шарами.
`back` має суцільний фон `#06080d`, `mid` і `floor` прозорі. Сума шарів = повний файл мінус
кінематографічні смуги (див. нижче).

## Замінені `<pattern>`-заливки (T-V2-01 01c, 2026-09-12)
ThorVG у Godot 4.7.2 не малює `<pattern>`: заливка `url(#…)` рендериться як відсутня (перевірено
растеризацією через `Image.load_svg_from_string` — крізь прямокутник з патерном видно те, що під ним).
Тому у **всіх дванадцяти похідних** (і лише в них, оригінали в `../level0/` не чіпались) чотири патерни
з `<defs>` замінено на плоскі еквіваленти за середнім покриттям, а порожній `<defs>` прибрано:

| Патерн | Було | Стало |
|---|---|---|
| `hatch` | лінія 1 px чорна opacity 0.35 у клітинці 6×6, поворот 35° | `fill="#000000" fill-opacity="0.06"` |
| `dots` | коло r 1 чорне opacity 0.3 у клітинці 8×8 | `fill="#000000" fill-opacity="0.02"` |
| `stripes` | смуги 6/6 `#e8b23a` / `#1a1a1a`, поворот 45° | `fill="#816634"` (середнє двох кольорів) |
| `grate` | рамка `#2c3550` 1.5 px у клітинці 10×10 | `fill="#2c3550" fill-opacity="0.28"` |

Візуально втрачено штрихування скель/стін і сітку решіток; попереджувальні смуги на кліті й дверях
стали суцільними приглушено-жовтими. Якщо потрібні справжні смуги/решітки — малювати їх геометрією
(окремі `rect`), не патерном.

## Як відтворити
Скрипт вирізки (Python, `xml.etree`) лежав у scratchpad сесії 2026-09-12 (`svgwork/derive.py`); він
видаляє елементи за індексами верхнього рівня з перевіркою сигнатури (tag + fill/stroke/transform/d),
тож при зміні оригіналів впаде, а не вирізатиме навмання. Перевірка — растеризація через
`Image.load_svg_from_string` у headless Godot і візуальний огляд PNG.
